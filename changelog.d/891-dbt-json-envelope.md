### sverify-dbt prints sverify's JSON document, and takes only sverify's public API

`sverify-dbt check --format json` prints the envelope of `sverify check --format json` (`format`, `sverify`, `command`, `exit`, `status`, `items`, `findings`, `error`), with the dbt version and adapter beside it. Each model is an item (`status` `refused` for a model sverify cannot read, added to the schema) and each unproved test a finding with sverify's code, which `sverify explain` takes. A failed check prints the envelope with its `error` as well. sverify-dbt catches `UnsupportedError` for a refusal instead of every `ValueError`, and a test lists the few names it still takes outside the public API ([#891](https://github.com/AlexanderNenninger/substrait-lean/issues/891)).
