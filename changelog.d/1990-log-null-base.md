`log(x, base)` with a NULL argument is NULL at every engine, also where the other argument would raise (`log(NULL, 0)`, `log(NULL, 1)`), as the reference reads a call with both arguments present only (#1990). DuckDB's written SQL raised there, since its raise helper does not return NULL for a NULL guard column; the shared writer now guards the domain check against a NULL argument. `log(1.0, 0)` still raises.
