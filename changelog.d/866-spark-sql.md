### Spark SQL input

`sv.sql(query, dialect="spark")` reads Spark SQL as Spark 4.3 computes it under the Spark profile's settings, ANSI mode among them ([#866](https://github.com/AlexanderNenninger/substrait-lean/issues/866)). The first slice covers `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, joins, `ORDER BY`, `LIMIT`, set operations, comparisons, logic, `CASE`, `coalesce`, integer arithmetic, `||`, `length`, `count` (with an argument or `*`), `min` and `max`, over `INT` and `BIGINT`, booleans and strings, with order (`<`, `min`, `max`, `ORDER BY`) on integers only. Every other construct is refused with #866 named. A name that matches an input only in another case is refused, since the profile resolves names by their case. The report names the Spark version and the settings the reading assumes. Reading Spark SQL needs no JVM.
