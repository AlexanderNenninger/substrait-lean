### `Report.verdict` replaces `Report.proved` (breaking)

`Report.proved`, a boolean, is removed with no alias. `Report.verdict` is a `sverify.Verdict`: `proved` (every postcondition holds and no run raises), `proved_with_checks` (the same, but a run stops where a check of `Report.assumed` fails on the data) or `unproved`. `bool(report.verdict)` raises `TypeError`, so `assert report.verdict` cannot pass on `unproved`; compare with the value you expect. `Report.run` and `on_unproved` treat both proved values as the old `proved`. `CheckedCondition.proved` stays a boolean. In the JSON report, `verdict` holds the value, `summary` the first line of `str(report)`, and `proved` stays as it was. sverify-dbt's `CheckResult.proved` (a list) is renamed `proved_tests` for one name per concept ([#1484](https://github.com/AlexanderNenninger/substrait-lean/issues/1484), finding 6).
