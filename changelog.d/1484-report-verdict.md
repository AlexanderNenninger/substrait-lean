### `Report.verdict` replaces `Report.proved` (breaking)

`Report.proved`, a boolean, is removed with no alias. `Report.verdict` is a `sverify.Verdict`: `proved` (every postcondition holds and no run raises), `proved_with_checks` (the same, but a run stops where a check of `Report.assumed` fails on the data) or `unproved`. `bool(report.verdict)` raises `TypeError`, so `assert report.verdict` cannot pass on `unproved`; compare with the value you expect. `Report.run` and `on_unproved` treat both proved values as the old `proved`. `CheckedCondition.proved` stays a boolean. The report's JSON is format 3: `verdict` holds the value (format 2 held the first line of `str(report)`, which `summary` holds now), and `proved` stays, derived from `verdict`, until 2.0. `Report.from_json` reads formats 2 and 3. sverify-dbt's `CheckResult.proved` (a list) is renamed `proved_tests` for one name per concept ([#1484](https://github.com/AlexanderNenninger/substrait-lean/issues/1484), finding 6).
