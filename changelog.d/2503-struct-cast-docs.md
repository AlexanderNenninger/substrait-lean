### Struct casts are documented as refused

[Nested values](docs/nested-values.md#struct-casts) says that a cast to a type holding a struct is refused, names the workaround (cast the fields, or build the struct in SQL) and links the plan for pairing by name after 1.0 ([#2503](https://github.com/AlexanderNenninger/substrait-lean/issues/2503)).
