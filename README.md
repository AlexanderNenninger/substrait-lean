# Published notebooks

This branch holds the tour notebooks of `sverify` 0.3.0, as released on
PyPI, so that the molab links in the README open notebooks that match the
release. Each notebook installs `sverify==0.3.0` from PyPI instead of the
repository checkout.

It is written by the `publish-notebooks` job of `.github/workflows/wheels.yml`,
one commit per release; don't edit it by hand. The sources are in
[`notebooks/` at v0.3.0](https://github.com/AlexanderNenninger/substrait-lean/tree/v0.3.0/notebooks).
